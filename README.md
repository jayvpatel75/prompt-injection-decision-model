# Prompt injection decision model

A small model that reads a piece of text and scores the risk: whether it is a prompt injection, and how severe. It returns a choice and a probability. It does not chat.

Training runs in Google Colab. This laptop's built-in graphics chip does not train the model.

If you are setting this up, open [INSTRUCTIONS.md](INSTRUCTIONS.md) and do the steps yourself.
